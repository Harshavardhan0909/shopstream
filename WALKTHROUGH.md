# Walkthrough video script (about 3 minutes)

Record with OBS Studio, Loom or the built-in screen recorder (Win+Alt+R on Windows, Cmd+Shift+5 on Mac). Use the live GitHub Pages link in the browser.

| Time | Do on screen | Say |
|------|--------------|-----|
| 0:00 | Show the live URL and the GitHub repo | "This is ShopStream, an e-commerce storefront I built with HTML, CSS and JavaScript, deployed on GitHub Pages." |
| 0:20 | Scroll the home page; let the banner rotate | "The home page has a hero banner and category cards." |
| 0:40 | Search "keyboard", then clear it | "Search works across titles and categories." |
| 1:00 | Click Electronics; apply Under ₹5,000 and 4★ & up; sort by price | "Filters and sorting update results instantly." |
| 1:30 | Open a product modal | "Each product has a detail view with discount and features." |
| 1:50 | Add 2 items, open cart, change quantity, delete one | "The cart is saved in localStorage, so it survives a refresh." Refresh the page to prove it. |
| 2:20 | Proceed to Buy; fill the form (card 4242 4242 4242 4242, CVV 123) | "Checkout calculates delivery and tax." |
| 2:40 | Place order, then open "Returns & Orders" | "The order is confirmed and stored in order history." |
| 2:55 | Show the repo, README and the Actions deploy run | "Every push to main redeploys automatically." |

Tips: use a 1080p window, hide bookmarks, and also record a short mobile view (browser dev tools → device toolbar) to show responsiveness.
